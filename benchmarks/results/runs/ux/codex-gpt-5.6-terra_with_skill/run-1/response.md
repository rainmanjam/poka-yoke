Not as the primary safeguard. A generic “Are you sure?” modal becomes click-through muscle memory.

For workspaces, use **soft delete + Trash with a retention period** (control): deletion is reversible, so accidental clicks don’t become data loss. Add an immediate **Undo** toast as a fast recovery path.

If permanent deletion is ever needed, make it a separate action and require typing the workspace name, with the exact workspace and affected project/file counts shown. That’s a proportional warning; the modal alone isn’t.
