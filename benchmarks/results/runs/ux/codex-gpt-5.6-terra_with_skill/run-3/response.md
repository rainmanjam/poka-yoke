Not as the main safeguard. A generic “Are you sure?” modal becomes click-through theater.

Use a reversible delete instead: move workspaces to a 30-day trash / soft-delete state, with an immediate **Undo** action. That’s control: an accidental deletion no longer causes permanent loss.

If permanent deletion is needed, then use a deliberate warning:

- Name the exact workspace and what will be lost.
- State retention/reversibility honestly.
- For high-value workspaces, require typing its name to confirm.
- Make “Cancel” the default focus; label the action “Delete workspace,” never “OK.”

Also make the server enforce the retention and authorization rules—hiding or gating the UI alone won’t protect the data.
