According to this repository's own philosophy in `AGENTS.md`, the short answer is: **stop trying to get people to follow it.** 

The rule that governs this project is: *"If your change relies on someone remembering something, it is not finished."* Announcements in standup, pinned messages in Slack, and updates to `CONTRIBUTING.md` are all forms of training. And as the docs say, training degrades.

To fix this permanently, you need to upgrade from a *warning* (telling people) to a **device** (a control that makes the mistake impossible). Specifically, you should add a mechanical check to `.github/workflows/validate.yml` that automatically fails any PR that is unformatted or untyped. 

I've drafted a detailed [Implementation Plan](conversation://246ade7d-26ba-4cf5-9544-3013cf458e04) to set up these devices using `ruff` (which you already use in CI) and a type checker like `mypy`. 

Please review the plan—there are a couple of open questions about the specific tools you want to use and how to handle any existing unformatted/untyped code. Once you clarify those, I can implement the checks for you.
