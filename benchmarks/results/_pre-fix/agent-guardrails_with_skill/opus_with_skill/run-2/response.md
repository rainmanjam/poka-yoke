## The diagnosis

Nothing is wrong with your wording. Caps and repetition are the problem's *symptom*, not its cure.

An instruction in CLAUDE.md is **rung 0** on Shingo's ladder — it isn't a poka-yoke at all, it's training. Training degrades, and an agent is the worst possible trainee: no memory of yesterday's correction, a context that gets compacted mid-task, and subagents that were never handed the file. One-in-ten is roughly what rung 0 *looks like* when it's working as designed. Shouting louder moves it to maybe one-in-fifteen. It never reaches zero, and force-push is irreversible, so the residual rate is the whole risk.

The tell you already have: **you repeated the rule.** That's the signal to stop writing instructions and install a device.

`★ Insight ─────────────────────────────────────`
Both your rules are *irreversible and outward-facing* — the exact category where only Control (rung 1) counts. Reversible things (ordinary edits) don't need gates; git undoes them. Gate the things git can't undo.
`─────────────────────────────────────────────────`

## The devices

**1. Deny rules** — `.claude/settings.json`, committed so it exists for the team, not just whoever set it up:

```jsonc
{ "permissions": { "deny": [
  "Bash(git push --force:*)", "Bash(git push -f:*)",
  "Edit(./src/generated/**)", "Write(./src/generated/**)"
]}}
```

**2. A PreToolUse hook** for the force-push case, because the pattern needs logic — `--force-with-lease` is the safe form and a blanket string match either blocks it wrongly or misses `-f`. Your own repo already ships a tested one: `plugins/poka-yoke/assets/devices/claude-hooks/guard_dangerous_commands.py`. Copy it to `.claude/hooks/` in the target repo.

**3. A header in every generated file** (`// AUTOGENERATED — edits are overwritten by <cmd>`) plus a CI check that regenerating produces no diff. That catches the path the deny rule can't see — an agent writing to the file via `Bash`.

**The deny message is the device, not the denial.** A bare "denied" makes the agent invent a workaround, usually worse. Name what was blocked, why, and the safe alternative.

**4. What stays in CLAUDE.md:** rewrite the two rules as facts, not commands — *"`src/generated/` is produced by `<cmd>`; source of truth is `<x>`"*. Facts help; hopes don't.

Rung reached: **Control** for both, via the tool boundary. The one gap is a human running the force-push in a terminal — that needs branch protection on the remote, which is also Control but lives on GitHub's side.
