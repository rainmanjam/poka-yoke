You're doing what most people do with CLAUDE.md: treating prose as a rule when it's actually **rung 0** — training, not a device. Shingo's framing (from the poka-yoke skill this plugin implements) is blunt about this: *"A comment, a docstring, a wiki page, or a line in CLAUDE.md saying 'don't do X' is not a poka-yoke. It is training. Training degrades."*

Why it degrades specifically for you at ~1-in-10:
- **Context pressure** — as the conversation grows and gets compacted/summarized, low-salience prose rules are exactly what gets dropped first.
- **Subagents** — if any work runs through a Task/subagent, it often doesn't inherit or re-read the parent's CLAUDE.md.
- **Caps and repetition don't add enforcement** — writing it twice in caps increases emphasis, not mechanism. The model has no way to "check" a rule; it can only try to remember it.

The fix is to move both rules off rung 0 onto **rung 1 (control)** — deny the action at the tool boundary so it's not a memory problem anymore:

**1. Force-push** — a `PreToolUse` deny rule. This plugin already ships one: `plugins/poka-yoke/assets/devices/claude-hooks/guard_dangerous_commands.py` matches `git push --force`/`-f` (allowing `--force-with-lease`) and returns a deny with a reason. Belt-and-suspenders: also add GitHub branch protection on the remote, since a local hook only protects while it's wired up — it doesn't stop a push that bypasses your machine's settings entirely.

**2. `src/generated/` edits** — a settings.json deny rule (`Edit(./src/generated/**)`, `Write(./src/generated/**)`), plus a `// DO NOT EDIT — generated by ...` header in the files themselves so even a human or a tool without the hook gets the same signal, plus ideally a CI check that regenerates and diffs to catch drift.

Two decisions before I implement anything:
- For force-push: block it outright, or allow `--force-with-lease` (safe form, still lets you rewrite your own unpushed commits)?
- Do you want this wired into *this* repo's `.claude/settings.json`, or is the CLAUDE.md you mentioned in a different project?
